# Student-Performance-Analytics-Dashboard
🚀 **Project Showcase: GradeGlow – Student Performance Analytics Dashboard**

I'm excited to share my latest Python project, **GradeGlow**, a smart student performance analytics dashboard developed as part of my learning journey in Data Analytics.

📊 **What does GradeGlow do?**
- Analyzes student marks and calculates total and average scores
- Identifies grades and pass/fail status
- Displays subject-wise performance through interactive charts
- Highlights top-performing students
- Provides an organized student records dashboard

🛠️ **Technologies Used:**
Python | Streamlit | Pandas | Plotly
